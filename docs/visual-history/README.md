# 視覺演進檔案櫃

背景場景在 2026-08-03 一天內改過九版。其中**兩版從未進入 git**——
它們只存在於工作區，就被下一個方向覆蓋了。這個資料夾把它們保留下來。

## 收錄

| 檔案 | 版本 | 當時的方向 | 為何沒進 git |
|---|---|---|---|
| `v02-fullscreen-pool.css` | v02 | 整個畫面就是池面，往下看進水裡 | 下一個指示在 commit 之前就到了 |
| `v03-lake-horizon.css` | v03 | 上半夜空、下半水面，中間一條地平線 | 同上，存活不到一輪 |

## 這些檔案是重建的，不是原始快照

原始工作區狀態已經不存在。這兩個檔案是**依當時對話紀錄中的 CSS 原文重新組合**的，
以 `52afd9a`（那個時期的色調）為基底，只換掉背景區塊。

結構與數值忠於當時寫下的內容，但**不能宣稱位元層級等同**於當初跑在瀏覽器裡的那份。
要精確的歷史請看 git log；要看視覺演進看這裡。

## 為什麼不改寫歷史把它們補回去

`52afd9a` 之後的分支已經推上遠端。改寫歷史會讓已推送的 commit 全部換 hash，
代價遠大於「兩個中間版本沒有獨立 commit」這件事本身。
所以選擇往前加檔案，不往回改歷史。

## 教訓

方向轉得快的時候，**每個版本先 commit 再改下一版**。
一個 `wip:` commit 的成本是幾秒，事後重建的成本是這個資料夾。
